## Popis

Webová stránka predstavuje moju osobnú online vizitku.
Obsahuje profil, životopis, pracovné prostredie, týždenný rozvrh
a interaktívnu mapu s možnosťou pridávania vlastných bodov
a výpočtu vzdialenosti.

Stránka je vytvorená pomocou HTML5, CSS a JavaScriptu.
Na stránke s mapou používam knižnicu Leaflet a mapové podklady
OpenStreetMap.
